Recursion

Recursive definitions, recursive programs and proofs about them

Last modified: 2026-10-24 10:59:47 (PDT)

Source

The topics of this chapter follow Kameron Decker Harris’s Fall 2026 lecture notes on recursion and recursive functions. These come from those notes:

  • the two parts of a recursive definition, a base case and a recursive rule;
  • the recursive definitions of the natural numbers and of the strings over an alphabet;
  • the three questions to ask when writing a recursive function: the base case, the recursive call and the combination;
  • the definition of a recursive algorithm.

Everything else is new: the exercises, the other examples, the Racket functions, the algorithm, the theorems and their proofs.

1 Recursive definitions

Exercise 1 (Double and subtract one) A sequence (Definition: Sequence) starts with \(a_0 = 2\), and each later term is twice the term before it, minus 1. Find \(a_1\), \(a_2\), \(a_3\), \(a_4\) and \(a_5\).

Solution 1. Each term comes from the one before it:

\[ \begin{aligned} a_1 &= 2 \cdot 2 - 1 = 3, \\ a_2 &= 2 \cdot 3 - 1 = 5, \\ a_3 &= 2 \cdot 5 - 1 = 9, \\ a_4 &= 2 \cdot 9 - 1 = 17, \\ a_5 &= 2 \cdot 17 - 1 = 33. \end{aligned} \]

To find \(a_5\) this way, we had to find \(a_1\) through \(a_4\) first.

Definition 1 (Recursive definition) Let \(n_0\) be an integer (Definition: Integers). A recursive definition (Wikipedia contributors 2026f) of a function (Definition: Function (map, mapping, transformation)) \(f\) on the integers \(n \ge n_0\) has two parts:

  1. Base case: the value of \(f\) is given directly at \(n_0\), and possibly at a few more of the smallest inputs.
  2. Recursive rule: \(f(n)\) at every other input \(n\) is given in terms of the values of \(f\) at inputs that are smaller than \(n\) and at least \(n_0\).

Example 1 (The double-minus-one sequence, defined recursively) The sequence of Exercise 1 has a recursive definition (Definition 1) with \(n_0 = 0\). Its base case is

\[ a_0 = 2, \]

and its recursive rule is

\[ a_n = 2 a_{n-1} - 1 \quad\text{for every integer } n \ge 1. \]

The recursive rule gives \(a_n\) from the single value \(a_{n-1}\) just before it, so this is a recursively defined sequence (Definition: Recursively defined sequence) with \(m = 1\).

Definition 2 (Floor) The floor \(\mathopen{}\left\lfloor x\right\rfloor\mathclose{}\) of a real number (Definition: Real numbers) \(x\) (Wikipedia contributors 2026b) is the largest integer (Definition: Integers) that is at most \(x\).

Example 2 (Some floors) By Definition 2,

  • \(\mathopen{}\left\lfloor 3.7\right\rfloor\mathclose{} = 3\), since 3 is an integer at most 3.7 and 4 is not;
  • \(\mathopen{}\left\lfloor 5\right\rfloor\mathclose{} = 5\), since 5 is already an integer;
  • \(\mathopen{}\left\lfloor-1.5\right\rfloor\mathclose{} = -2\), since \(-2\) is at most \(-1.5\) and \(-1\) is not.

For a natural number (Definition: Natural numbers (our convention)) \(n\), the floor \(\mathopen{}\left\lfloor n / 10\right\rfloor\mathclose{}\) is \(n\) with its last decimal digit removed, such as \(\mathopen{}\left\lfloor 2026 / 10\right\rfloor\mathclose{} = \mathopen{}\left\lfloor 202.6\right\rfloor\mathclose{} = 202\).

Example 3 (Counting digits) Define a function \(d\) on the natural numbers (Definition: Natural numbers (our convention)) by

\[ d(n) = \begin{cases} 1 & \text{if } n \le 9, \\ 1 + d\mathopen{}\left(\mathopen{}\left\lfloor n / 10\right\rfloor\mathclose{}\right)\mathclose{} & \text{if } n \ge 10, \end{cases} \]

where \(\mathopen{}\left\lfloor n / 10\right\rfloor\mathclose{}\) is the floor (Definition 2) of \(n / 10\), which is \(n\) with its last decimal digit removed. The first line is the base case and the second is the recursive rule (Definition 1). For \(n \ge 10\), the input \(\mathopen{}\left\lfloor n / 10\right\rfloor\mathclose{}\) is at least 1 and at most \(n / 10\), which is less than \(n\), so the recursive rule uses a smaller input, but usually not \(n - 1\). For example,

\[ \begin{aligned} d(2026) &= 1 + d(202) \\&= 1 + 1 + d(20) \\&= 1 + 1 + 1 + d(2) \\&= 1 + 1 + 1 + 1 \\&= 4, \end{aligned} \]

and 2026 has 4 digits.

2 Recursively defined sets

Exercise 2 (Building a set of integers) A set (Definition: Set) \(S\) of integers is built by two rules:

  • \(1 \in S\);
  • if \(x \in S\), then \(x + 2 \in S\) and \(3x \in S\).

Every element of \(S\) comes from these two rules. Find every element of \(S\) that is less than 12.

Solution 2. Starting from 1 and adding 2 again and again gives \(1, 3, 5, 7, 9, 11\), so all six are in \(S\). Tripling gives nothing new below 12: \(3 \cdot 1 = 3\) and \(3 \cdot 3 = 9\) are already in the list, and tripling 5 or more gives at least 15. Both rules turn an odd number into an odd number, so no even number is in \(S\). So the elements of \(S\) less than 12 are \(1, 3, 5, 7, 9\) and \(11\).

Definition 3 (Recursively defined set) A recursively defined set (Wikipedia contributors 2026f) is a set (Definition: Set) given by two parts, named as in Definition 1:

  1. a base case, which names some elements of the set directly;
  2. a recursive rule, which says how to build new elements of the set from elements already in it.

The set has no other elements: each of its elements comes from the base case by applying the recursive rule a finite number of times.

Example 4 (The natural numbers, defined recursively) The natural numbers (Definition: Natural numbers (our convention)) are a recursively defined set (Definition 3). The base case is \(1 \in \mathbb{N}\), and the recursive rule is that if \(n \in \mathbb{N}\), then \(n + 1 \in \mathbb{N}\). The base case gives 1, one application of the rule gives \(1 + 1 = 2\), a second gives \(2 + 1 = 3\), and so on. The non-negative integers (Definition: Non-negative integers) have the same recursive rule, with the base case \(0 \in \mathbb{N}_0\).

Definition 4 (Alphabet) An alphabet (Wikipedia contributors 2026a) is a finite, non-empty set (Definition: Set), whose elements are called its symbols. An alphabet is often written \(\Sigma\), the capital Greek letter sigma.

Example 5 (Three alphabets) Each of these sets is an alphabet (Definition 4):

  • \(\mathopen{}\left\{0, 1\right\}\mathclose{}\), the two binary digits;
  • \(\mathopen{}\left\{\mathtt{A}, \mathtt{C}, \mathtt{G}, \mathtt{T}\right\}\mathclose{}\), the four bases of DNA;
  • \(\mathopen{}\left\{\mathtt{a}, \mathtt{b}, \ldots, \mathtt{z}\right\}\mathclose{}\), the 26 lowercase letters of English.

The set of all integers is not an alphabet, because it is not finite.

Definition 5 (String) Let \(\Sigma\) be an alphabet (Definition 4). The set \(\Sigma^*\) of strings over \(\Sigma\) (Wikipedia contributors 2026g) is the recursively defined set (Definition 3) with

  • base case: the empty string \(\lambda\), which has no symbols, is in \(\Sigma^*\);
  • recursive rule: if \(w \in \Sigma^*\) and \(x \in \Sigma\), then \(w x \in \Sigma^*\), where \(w x\) is the string \(w\) followed by the symbol \(x\).

Racket and Python write the empty string "".

Example 6 (Building a string of DNA bases) Let \(\Sigma = \mathopen{}\left\{\mathtt{A}, \mathtt{C}, \mathtt{G}, \mathtt{T}\right\}\mathclose{}\). The string \(\mathtt{GAT}\) is in \(\Sigma^*\) (Definition 5), by three applications of the recursive rule:

  • \(\lambda \in \Sigma^*\) and \(\mathtt{G} \in \Sigma\), so \(\lambda \mathtt{G} = \mathtt{G}\) is in \(\Sigma^*\);
  • \(\mathtt{G} \in \Sigma^*\) and \(\mathtt{A} \in \Sigma\), so \(\mathtt{GA} \in \Sigma^*\);
  • \(\mathtt{GA} \in \Sigma^*\) and \(\mathtt{T} \in \Sigma\), so \(\mathtt{GAT} \in \Sigma^*\).

The string \(\mathtt{GAU}\) is not in \(\Sigma^*\), since the rule adds only symbols of \(\Sigma\), and \(\mathtt{U} \notin \Sigma\).

Definition 6 (Palindrome) A palindrome (Wikipedia contributors 2026d) is a string (Definition 5) that reads the same backward as forward: its \(i\)th symbol equals its \(i\)th symbol from the end, for every \(i\).

Example 7 (Some palindromes) Over the alphabet of lowercase letters, \(\mathtt{noon}\) and \(\mathtt{racecar}\) are palindromes (Definition 6), and so is \(\mathtt{abba}\), from Exercise: Completing a palindrome. The string \(\mathtt{recur}\) is not a palindrome: backward it reads \(\mathtt{rucer}\). The empty string and every string of one symbol are palindromes.

3 Recursion in Racket

Exercise 3 (Tracing a recursive Racket function) The Racket function binary takes a non-negative integer (Definition: Non-negative integers) n and returns a string:

(define (binary n)
  (if (< n 2)
      (number->string n)
      (string-append (binary (quotient n 2))
                     (number->string (remainder n 2)))))

Here

  • (if test a b) returns a when test is true and b when it is false;
  • (quotient n 2) is \(\mathopen{}\left\lfloor n / 2\right\rfloor\mathclose{}\), the floor (Definition 2) of \(n / 2\);
  • (remainder n 2) is the remainder, 0 or 1, left after dividing n by 2;
  • number->string turns a number into the string of its digits;
  • string-append joins two strings into one.

Run (binary 6) by hand: write down each call of binary that it makes, and the string that each call returns.

Solution 3. Since \(6 \ge 2\), (binary 6) calls (binary 3), because \(\mathopen{}\left\lfloor 6 / 2\right\rfloor\mathclose{} = 3\), and puts "0", the remainder of 6 divided by 2, after its result. Since \(3 \ge 2\), (binary 3) calls (binary 1) and puts "1" after its result. Since \(1 < 2\), (binary 1) returns "1" without calling binary again. Replacing each call with what it returns:

(binary 6)
= (string-append (binary 3) "0")
= (string-append (string-append (binary 1) "1") "0")
= (string-append (string-append "1" "1") "0")
= (string-append "11" "0")
= "110"

So (binary 1) returns "1", (binary 3) returns "11", and (binary 6) returns "110". That is 6 written in base 2, since \(1 \cdot 4 + 1 \cdot 2 + 0 \cdot 1 = 6\).

Remark 1 (Three questions for writing a recursive function). A Racket function that calls itself, such as binary in Exercise 3, answers three questions:

  • Base case. Which inputs does it answer directly? For binary, the inputs 0 and 1, whose base-2 form is the single digit "0" or "1".
  • Recursive call. Which smaller input does it call itself on? For binary, the input \(\mathopen{}\left\lfloor n / 2\right\rfloor\mathclose{}\), which is less than \(n\) when \(n \ge 2\).
  • Combination. How does it turn the result of the recursive call into its own answer? For binary, it puts the last base-2 digit of \(n\), the remainder of \(n\) divided by 2, after the result.

The base case is the branch of the if that does not call the function, and the recursive call and the combination make up the other branch.

Example 8 (Counting digits in Racket) The recursive definition of \(d\) in Example 3 becomes a Racket function line by line:

(define (digits n)
  (if (< n 10)
      1
      (+ 1 (digits (quotient n 10)))))

Following Remark 1:

  • the base case answers 1 for every input less than 10;
  • the recursive call is (digits (quotient n 10)), on \(\mathopen{}\left\lfloor n / 10\right\rfloor\mathclose{}\), which is less than \(n\);
  • the combination adds 1 to the result of the recursive call.

(digits 2026) calls (digits 202), (digits 20) and (digits 2) in turn, as in Example 3, and returns 4.

4 Lists

Exercise 4 (Building a list with cons) In Racket, empty is the list with no elements, and (cons x xs) is the list whose first element is x, followed by the elements of the list xs. For example, (cons 5 empty) is the one-element list '(5). Write the list '(7 2 9) using only cons, empty and numbers.

Solution 4. Build the list from its last element forward:

  • (cons 9 empty) is '(9);
  • (cons 2 (cons 9 empty)) is '(2 9);
  • (cons 7 (cons 2 (cons 9 empty))) is '(7 2 9).

So '(7 2 9) is (cons 7 (cons 2 (cons 9 empty))).

Definition 7 (List) Let \(A\) be a set (Definition: Set). The set of lists of elements of \(A\) (Wikipedia contributors 2026c) is the recursively defined set (Definition 3) with

  • base case: the empty list, written \(\mathtt{empty}\), is a list;
  • recursive rule: if \(x \in A\) and \(L\) is a list, then \(\operatorname{cons}(x, L)\) is a list, whose first element is \(x\) and whose rest is \(L\).

Racket writes the empty list as empty or '(), and \(\operatorname{cons}(x, L)\) as (cons x L), and (first L) and (rest L) return the two parts of a list that is not empty. Racket also has the older names car for first and cdr for rest. Python writes the empty list [].

Example 9 (Taking a list apart) Let L be the list '(7 2 9) (Definition 7), which Solution 4 builds as (cons 7 (cons 2 (cons 9 empty))). Then

  • (first L) is 7, and (rest L) is '(2 9);
  • (first (rest L)) is 2;
  • (rest (rest (rest L))) is empty.

(first empty) raises an error, since the empty list is not built by cons and has no first element.

Definition 8 (Length of a list) The length \(\operatorname{len}(L)\) of a list \(L\) (Definition 7) is defined recursively, following the two parts of the definition of a list:

\[ \begin{aligned} \operatorname{len}(\mathtt{empty}) &= 0, \\ \operatorname{len}\mathopen{}\left(\operatorname{cons}(x, L)\right)\mathclose{} &= 1 + \operatorname{len}(L). \end{aligned} \]

Example 10 (The length of '(7 2 9)) In Racket, the definition of length (Definition 8) is

(define (len L)
  (if (empty? L)
      0
      (+ 1 (len (rest L)))))

where (empty? L) tests whether L is the empty list. Replacing each call with the recursive rule:

(len '(7 2 9))
= (+ 1 (len '(2 9)))
= (+ 1 (+ 1 (len '(9))))
= (+ 1 (+ 1 (+ 1 (len '()))))
= (+ 1 (+ 1 (+ 1 0)))
= 3

Racket’s built-in length gives the same values.

Definition 9 (Appending two lists) The append \(\operatorname{app}(L, M)\) of two lists \(L\) and \(M\) (Definition 7), the list of the elements of \(L\) followed by the elements of \(M\), is defined recursively on \(L\):

\[ \begin{aligned} \operatorname{app}(\mathtt{empty}, M) &= M, \\ \operatorname{app}\mathopen{}\left(\operatorname{cons}(x, L), M\right)\mathclose{} &= \operatorname{cons}\mathopen{}\left(x, \operatorname{app}(L, M)\right)\mathclose{}. \end{aligned} \]

Example 11 (Appending '(1 2) and '(3)) In Racket, the definition of append (Definition 9) is

(define (app L M)
  (if (empty? L)
      M
      (cons (first L) (app (rest L) M))))

The recursion takes L apart and leaves M alone:

(app '(1 2) '(3))
= (cons 1 (app '(2) '(3)))
= (cons 1 (cons 2 (app '() '(3))))
= (cons 1 (cons 2 '(3)))
= '(1 2 3)

Racket’s built-in append gives the same values.

5 Recursive algorithms

Exercise 5 (Is it a palindrome?) The algorithm pal, in the pseudocode of Remark: How to read the pseudocode in this chapter, tests whether a string is a palindrome (Definition 6):

procedure pal(s)        // s is a string s[1] s[2] ... s[n] of n symbols
    if n <= 1
        return true
    if s[1] != s[n]
        return false
    return pal(s[2..n-1])   // s without its first and last symbols

Here != means \(\ne\), and s[2..n-1] is the string of the symbols s[2] through s[n-1], which is the empty string when \(n = 2\), since the range 2..1 is empty. Run pal(level) by hand: write down each call of pal that it makes, and what each call returns.

Solution 5.

Call \(n\) First and last symbols What the call does
pal(level) 5 l, l calls pal(eve)
pal(eve) 3 e, e calls pal(v)
pal(v) 1 returns true

pal(v) returns true, so pal(eve) returns true, and so pal(level) returns true: \(\mathtt{level}\) is a palindrome.

Definition 10 (Recursive algorithm) An algorithm (Definition: Algorithm) is recursive (Wikipedia contributors 2026e) if it solves a problem by calling itself on smaller inputs of the same problem and using what those calls return. The inputs that it answers without calling itself are its base cases, as in Definition 1.

Example 12 (pal is recursive) The algorithm pal of Exercise 5 is recursive (Definition 10). On a string of \(n \ge 2\) symbols whose first and last symbols match, it calls itself on the string without those two symbols, which has \(n - 2\) symbols, and returns what that call returns.

It answers directly in two cases: when \(n \le 1\), since the empty string and a single symbol read the same backward, and when the first and last symbols differ. For example, pal(recur) finds that the first and last symbols are both r, and calls pal(ecu). That call finds e and u, which differ, and returns false, so pal(recur) returns false.

6 Proofs about recursive definitions

Exercise 6 (Guessing a formula) Compare each term \(a_0, a_1, \ldots, a_5\) of the sequence in Solution 1 with the power \(2^n\), and guess a formula for \(a_n\) that does not use the earlier terms.

Solution 6.

\(n\) 0 1 2 3 4 5
\(a_n\) 2 3 5 9 17 33
\(2^n\) 1 2 4 8 16 32

Each term is one more than the power below it, so a good guess is \(a_n = 2^n + 1\). Six terms do not prove the guess for every \(n\).

Theorem 1 (A formula for the double-minus-one sequence) Let \(a_0, a_1, \ldots\) be the sequence with \(a_0 = 2\) and \(a_n = 2 a_{n-1} - 1\) for every integer \(n \ge 1\) (Example 1). Then \(a_n = 2^n + 1\) for every non-negative integer \(n\).

Definition 11 (Structural induction) Structural induction (Wikipedia contributors 2026h) is a way to prove that every element of a recursively defined set (Definition 3) has a property \(P\), in two steps:

  1. Base case. Show that every element that the set’s base case names has \(P\).
  2. Inductive step. Show that whenever the recursive rule builds a new element from elements that have \(P\), the new element has \(P\) too.

Example 13 (Every element of \(S\) is odd) Let \(S\) be the set of Exercise 2. It is a recursively defined set (Definition 3), with base case \(1 \in S\) and recursive rule that if \(x \in S\), then \(x + 2 \in S\) and \(3x \in S\). We use structural induction (Definition 11) to show that every element of \(S\) is a positive odd (Definition: Even integer) integer.

Base case. The base case names 1, and \(1 = 2 \cdot 0 + 1\) is positive and odd.

Inductive step. Let \(x \in S\) be a positive odd integer, so \(x = 2j + 1\) for some integer \(j \ge 0\). The recursive rule builds \(x + 2\) and \(3x\) from \(x\), and

\[ \begin{aligned} x + 2 &= 2(j + 1) + 1, \\ 3x &= 6j + 3 = 2(3j + 1) + 1, \end{aligned} \]

which are positive and odd, since \(j + 1\) and \(3j + 1\) are non-negative integers.

So every element of \(S\) is a positive odd integer. Every positive odd integer \(2j + 1\) is in \(S\) too, since it comes from 1 by adding 2 a total of \(j\) times. So \(S\) is the set of positive odd integers, as Solution 2 found for the elements less than 12.

Remark 2 (Why structural induction works). Every element of a recursively defined set (Definition 3) comes from the base case by applying the recursive rule some number \(k \ge 0\) of times. Let \(Q(k)\) be the claim that every element built with \(k\) applications of the rule has the property \(P\). Strong induction (Definition: Proof by strong induction) on \(k\) proves \(Q(k)\) for every \(k \ge 0\):

  • an element built with 0 applications is named by the base case, so it has \(P\) by the base case of Definition 11;
  • an element built with \(k \ge 1\) applications comes, by its last application, from elements built with fewer applications, which have \(P\) by the strong induction hypothesis, so it has \(P\) by the inductive step.

So every element of the set has \(P\).

Theorem 2 (Appending adds lengths) For all lists \(L\) and \(M\) (Definition 7),

\[ \operatorname{len}\mathopen{}\left(\operatorname{app}(L, M)\right)\mathclose{} = \operatorname{len}(L) + \operatorname{len}(M), \]

where \(\operatorname{len}\) is the length (Definition 8) and \(\operatorname{app}\) is the append (Definition 9).

Theorem 3 (The function \(d\) counts digits) Let \(d\) be the function of Example 3. For every natural number \(n\),

\[ 10^{d(n) - 1} \le n < 10^{d(n)}, \]

so \(n\) has exactly \(d(n)\) decimal digits.
