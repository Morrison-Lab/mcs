# Welcome

This website collects the lecture notes for [CSCI 201](https://catalog.wwu.edu/search_advanced.php?cur_cat_oid=23&search_database=Search&search_db=Search&cpage=1&ecpage=1&ppage=1&spage=1&tpage=1&location=3&filter%5Bkeyword%5D=CSCI%20201), “Discrete Math and Functional Programming for Computer Scientists”, as taught in Winter Quarter 2027 at [Western Washington University](https://www.wwu.edu/) by [Douglas Ezra Morrison](https://d-morrison.github.io/).

The notes adapt [Kameron Decker Harris](https://cs.wwu.edu/harri267)’s Fall 2026 lecture notes for the course; his notes on logic, proofs, sets and induction are typed transcriptions of Scott Wehrwein’s Spring 2025 handwritten lecture notes. Each chapter’s collapsed **Source** note records what it draws on.

General mathematics that several courses share, such as logic, sets and functions, is kept in these notes. The [mathematics for data science](https://morrison-lab.github.io/mds/) notes link to these pages for those definitions.

The notes are available in multiple formats:

- **HTML Website**: Navigate using the navbar for easy access to all pages
- **RevealJS Slides**: Each chapter can generate a presentation format with `-slides.html` suffix
- **PDF Handouts**: Each chapter can generate a PDF handout with `-handout.pdf` suffix
- **DOCX Documents**: Each chapter can generate a Microsoft Word document with `.docx` extension
